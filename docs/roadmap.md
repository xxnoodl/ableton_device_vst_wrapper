# Roadmap and gates

1. M0: run one real VST3 parameter read/write/observe, automation, reload and target tests. Record evidence. Current status prototype.
2. M1: strict typed IR, migration/round-trip tests, portable project store, isolated VST3 inspector and redistributable test fixture after license review.
3. M2: studio shell then tested compressor layout, function selection, editing and undo. Demo data visibly identified.
4. M3: native Max rendering, binding lifecycle, measured panel profiles and reproducible device export.
5. M4–M6: verified derived graphs, real audio taps, hardening; optional AI and lawful legacy support last.
